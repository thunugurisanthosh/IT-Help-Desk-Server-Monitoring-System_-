#aws-linux-server-monitoring

## Overview
Built an AWS-based Linux server monitoring and IT help-desk lab using Ubuntu, Apache, Prometheus, Grafana, and Node Exporter.

## Environment
- **LINUX01** — Ubuntu, Apache, SSH, Node Exporter
- **MONITOR01** — Ubuntu, Prometheus, Grafana
- AWS EC2 + VPC
- Monitoring for CPU, memory, disk, network, and uptime

## Key Tasks
- Deployed Ubuntu EC2 servers on AWS
- Configured Apache and SSH
- Installed Node Exporter for Linux metrics
- Configured Prometheus to collect metrics
- Created Grafana monitoring dashboards
- Simulated and documented common IT incidents
- Added Linux troubleshooting and backup procedures

## Incidents
- INC001 — High CPU Usage
- INC002 — Low Disk Space
- INC003 — Apache Service Down
- INC004 — SSH Connectivity Issue
- INC005 — Network/DNS Issue

## Technologies
**AWS EC2 | AWS VPC | Ubuntu Linux | Apache | SSH | Prometheus | Grafana | Node Exporter | Monitoring | Troubleshooting | Incident Management | Backup**

## Outcome
Demonstrates practical skills in **Linux/System Administration, Cloud Support, IT Support, Monitoring, Troubleshooting, and Incident Management**.
